# ddiia-telegram-proxy

Cloudflare Worker, который принимает данные форм с ddiia.com и пересылает их в Telegram.
Токен бота и chat_id хранятся как зашифрованные Worker secrets — их нет ни в этом
репозитории, ни в коде, который получает браузер.

## Деплой

```bash
npx wrangler deploy
```

## Секреты

Задаются один раз (или при ротации токена):

```bash
npx wrangler secret put TELEGRAM_BOT_TOKEN
npx wrangler secret put TELEGRAM_CHAT_ID
```

Значения вводятся в интерактивном промпте и нигде не сохраняются в открытом виде.

## Разрешённые источники

Список доменов, которым разрешено слать запросы, задаётся переменной `ALLOWED_ORIGINS`
в `wrangler.toml` (через запятую).

## ⚠️ Ротация токена

Старый токен бота был закоммичен в открытом виде в основной репозиторий ddiia.com
(история git). Он считается скомпрометированным — создайте новый токен через
@BotFather, отзовите старый и обновите secret командой выше.
